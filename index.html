Instalação

O Claude Code e o Codex são ferramentas de programação com agentes para o seu fluxo de desenvolvimento. Eles enxergam o seu código, criam e editam arquivos e executam comandos nele.

Claude Code

  • No Mac, abra o Terminal e execute: npm install -g @anthropic-ai/claude-code
  • Se você não tem o npm, instale primeiro o Node.js em nodejs.org
  • No Windows, use o instalador nativo do site da Anthropic
  • Após a instalação, verifique se funciona digitando: claude

Veja o guia oficial de instalação e configuração do Claude Code para todos os detalhes.

Codex CLI

  • No Mac, abra o Terminal e execute: npm install -g @openai/codex
  • Se você não tem o npm, instale primeiro o Node.js em nodejs.org
  • No Windows, use o WSL2 (Subsistema do Windows para Linux) e execute o mesmo comando
  • Após a instalação, verifique se funciona digitando: codex

Veja a documentação oficial do Codex CLI para todos os detalhes.

Construa alguma coisa

  • Crie uma pasta para o projeto.
  • Abra uma janela de terminal nessa pasta e inicie o Claude (claude) ou o Codex (codex).
  • Peça ao Claude ou ao Codex para construir algo.
