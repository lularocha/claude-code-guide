Install Claude Code

Claude Code is an agentic coding tool for your development workflow. It can see your codebase, create and edit files, and run commands in it.

  • On Mac, open Terminal and run: npm install -g @anthropic-ai/claude-code
  • If you don't have npm, install Node.js first from nodejs.org
  • On Windows, use the native installer from Anthropic's website
  • After installation, verify it works by typing: claude

See the official Installation & Setup guide for full details.

Build Something

  • Create a project folder.
  • Point Claude to the folder — open a terminal window at that folder and start Claude by typing claude.
  • Ask Claude to build something.
Not sure what to ask for? You can use my Prompt Builder tool to craft a clear, detailed prompt.
